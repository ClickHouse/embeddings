Brute-force two-stage search over an Array(BFloat16) CODEC(Quantized(…)) column: scan the quantized codes, keep k × multiplier candidates, then rescore those against the full-precision vectors. Recall is measured against exact-cosine ground truth on the same ~100k-row pool, 20 random queries, k = 100. Green = 1.0, red = 0.0. The second line in each cell is the code size per vector (1 bit/dim for RaBitQ, 2 bits/dim for TurboQuant).
